🏷️ 知识点标签
等差数列数列求和公式高中数学必修5
🤖 AI解题分析

✅ 答案：S₁₀ = 155

利用等差数列求和公式：Sₙ = n·a₁ + n(n-1)d/2
📖 解题步骤
  1. ①套用公式 Sₙ = n·a₁ + n(n-1)d/2
  2. ②代入 n=10, a₁=2, d=3
  3. ③S₁₀ = 10×2 + 10×9×3/2 = 20 + 135 = 155
  4. ④验证：a₁=2, a₁₀=a₁+9d=29，S₁₀=(2+29)×10/2=155 ✓
⚠️ 常见错误提醒
注意公式中是 n(n-1)/2 而非 n(n+1)/2，同学们容易混淆！
